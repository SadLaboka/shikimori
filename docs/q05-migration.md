# Перенос q05: график активности

Статус: **перенос выполнен и опубликован 25 октября 2026 года** по явному
разрешению пользователя. Полный снимок q05 перенесён
в `BEGIN/END LOCAL ACTIVITY GRAPH` без оптимизации; импортов осталось семь.

## Объём и зависимости

Источник: `https://raw.githubusercontent.com/ed-main/ed-main.github.io/master/cssfiles/q05_animated_activity_graph.css`.
Снимок от 25 октября 2026 года: `vendor/q05_animated_activity_graph.css`, SHA256
`5402a3ef7af175e6931970fa02ffecfbcd64aa91f4d1fc334fd8795639eb0d07`.

В исходнике 38 обычных правил и четыре варианта `@keyframes fluctuations`:
WebKit, Mozilla, Opera и стандартный. Chromium распознаёт 40 правил (38 + два
варианта keyframes). В локальный CSS переносится исходник целиком, включая
неподдерживаемые этим браузером префиксы. Оптимизация не выполняется.

Правила задают прозрачный фон, скругления, анимацию 34 столбцов с длительностью
2,5 секунды и индивидуальными задержками, паузу на hover и исходные кадры
`fluctuations`. Своих media, `!important`, URL, изображений и импортов нет.
Используются переменные цветов E-design: `--very-high-rating`, `--average-rating`,
`--small-rating`, `--hundred`.

Локальный `profile-activity-pulse` отменяет animation-name старых столбцов через
`!important`, но наследует их длительности, задержки, число повторений и play-state
через `.bar-container` в `::before`. Поэтому импорт нельзя просто удалить как
неиспользуемый. Старая анимация остаётся запасным поведением вне локального
`@supports`. Её проверка в отдельном примере не эмулирует старый браузер.

## Порядок каскада

Блок вставляется перед `BEGIN LOCAL HISTORY BOOKMARKS`. Он пересекает десять правил
импорта постеров и два пользовательских правила AUTO-sticky от 1025px. Относительный
порядок истории, совместимости tooltip, раскладки и собственных настроек сохраняется.

Основная специфичность: `.bar.vertical .line` — `(0,3,0)`;
селекторы столбцов и running — `(0,4,0)`; hover — `(0,5,0)`;
`.bar.vertical .line .bar-container .bar` — `(0,5,0)`.
Пересекаемые правила постеров содержат фон и скругления, но относятся к обложкам
и подсказкам; AUTO-sticky задаёт position/top/max-height/overflow меню.
На реальном графике перестановка проверяется вычисленными свойствами, геометрией
и фазами анимаций. Новая произвольная комбинация классов в будущем этим не доказана:
глобальные селекторы q05 сохранены и не ограничиваются профилем автоматически.
Других определений `fluctuations` в наблюдённом развёрнутом CSS нет.

В E-design уже существует другой блок `.bar.vertical .line`. Аудит учитывает это
переопределение: требует одну точную копию каждого правила q05 и неизменный хэш
всех остальных правил. Проверка не удаляет из сравнения все совпадающие селекторы.
Для keyframes идентичность дополнительно включает заголовок at-rule: разные
keyframes и прочие правила без selectorText не смешиваются в одну группу.

## Воспроизведение

Из корня репозитория:

```powershell
pnpm --dir tools/preview test
node tools/preview/preview.mjs --check-layout --check-activity --widths 1440,390,360
```

`--check-activity` работает на профиле. Полная замена происходит в прежнем
`style#custom_css`, из основы удаляется только наблюдённый блок q05, предварительно
сверенный с vendor через CSSOM. За один запуск разрешён перенос одного известного
импорта. Проверяются отсутствие старой копии, дублей, точный применённый CSS,
сохранение остальных правил и позиции таблицы стилей.

Отдельный проход графика снимает одинаковое принудительное CSS-замораживание с обеих
версий и задаёт анимациям одинаковые времена через WAAPI. Он сравнивает все
вычисленные свойства узлов графика и их `::before`/`::after`, геометрию, hover
столбцов 1/17/34 и возврат без hover. На мобильном видимом графике x26 столбца 34
нет; такое состояние явно отмечается как пропущенное. Скрытый x34 всё равно
проверяется структурно и по вычисленным свойствам. Focus/active не присваиваются
неинтерактивным div искусственно.

## Ограничения

Проверка Chromium не заменяет Firefox и реальные устройства. Детерминированные
фазы не являются замером FPS/CPU или гарантией движения каждого кадра. GIF/WebP
вне графика не замораживаются. Все страницы сайта и будущая разметка не покрыты.
Изменение внешней основы требует повторной проверки источников, каскада и переменных.
Сам перенос не обещает ускорения: Shikimori уже разворачивает импорты.

Первоначальный этап выполнялся без публикации и git push; последующая публикация
разрешена пользователем отдельно.

## Результаты 25 октября 2026 года

Все 14 тестов пройдены. Кандидат на настоящем профиле совпал с опубликованной
версией на 1440, 390 и 360px: геометрия, вычисленные свойства, все остальные правила
и псевдоэлементы не изменились. 19 сравнений фаз и состояний графика совпали.
Два hover-случая для отсутствующего 34-го столбца x26 явно пропущены; для
реальных столбцов подтверждены `profile-activity-pulse` на `bar-container::before`
и CSS pause при наведении. Снимки графика просмотрены, визуальных отличий нет.

На 767, 768, 1023, 1024 и 1025px также пройден строгий аудит структуры, раскладки,
свойств и сохранности остального каскада. Отдельный ранний прогон сравнил фазы

вердикт был FAIL из-за окончаний строк, поэтому он не считается успешной миграцией.

## Найденные проблемы проверки

Первый аудит остановился из-за существующего второго правила `.bar.vertical .line`
из E-design. Проверка уточнена: переносимые точные определения учитываются отдельно,
а прочие объявления того же селектора остаются в хэше остального каскада. Тест
специально меняет padding второго правила и подтверждает изменение этого хэша.

Другой остановленный запуск обнаружил смену LF на CRLF при записи временного CSS
средствами Python на Windows: Chromium сохранил разницу в CSSOM многострочного
градиента комментариев. Кандидат пересохранён с исходными LF; сравнение остальных
правил не ослаблялось и пробелы внутри значений не удалялись.

Дополнительный контроль наличия активной анимации сначала смотрел на `line::before`,
хотя анимация находится на дочернем `bar-container::before`. Исправлен обход реальной
структуры: задержки и CSS pause читаются у line, а имя, clip-path и унаследованная
пауза — у псевдоэлемента bar-container. Основной CSS во время этих исправлений
оставался прежним.

Отрицательная CLI-проверка на трёх основных ширинах удаляет стандартные
`@keyframes fluctuations` только во временной копии. Ожидаемый результат — FAIL:
одного из 40 правил нет, хотя собственная анимация ещё работает. В повторе с LF
неизменность остальных правил подтверждена; ошибка не маскируется отличием строк.
Повторный запуск из основного файла на 1440, 390 и 360px также прошёл:
`2026-10-25T08-46-15-529Z/index.html`. В нём повторены структурный аудит q05,
регрессия раскладки и сравнение свойств/геометрии; полный набор фаз и hover
проверен ранее на побайтно совпадающем кандидате. Новая публикация, OAuth,
обращение к credentials и git push не выполнялись.
