## Ограничения и следующий шаг

LOCAL PASS не подтверждает удалённый URL: `remoteSourcesVerified: false`.
После отдельного разрешения на push нужно проверить URL обычным режимом
без `--local-imports`, затем перенести кандидат в основной CSS и повторить
предпросмотр. Публикация Shikimori требует своего разрешения; после неё нужна
сверка реального скомпилированного блока. Непроверенная ссылка в основной CSS
сейчас не записана.

Скриншоты сохранены, вручную не просматривались. GIF/WebP продолжают менять кадры,
поэтому pixel diff диагностический. Каталог, клубы, турниры, редактор и все
интерактивные состояния не проверялись отдельно в реальном DOM; full CSSOM
подтверждает неизменность правил, а не визуальную проверку всех страниц.
Отдельный `--check-history` не запускался. Media-условия не изменялись, поэтому
дополнительные ширины границ не прогонялись. Firefox, авторизованный вид и реальные
телефоны не покрыты. Визуальных изменений не ожидается по совпадению байтов/каскада;
улучшение мобильной версии или производительности этим переносом не заявляется.

Commit-URL сохраняет выбранную версию. Будущие обновления upstream требуют
отдельного сравнения; правки рабочей копии не обновляют импорт автоматически.
После main2 остаются main1 и main4; шрифты остаются внешними по решению пользователя.
