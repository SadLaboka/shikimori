# Изображения: локальный аудит и память

Читать при анализе ресурсов и кадров. Это исторические результаты 24 октября
2026 года, а не автоматически актуальная инвентаризация текущих URL.

## Состав оформления

`about.md` содержит BBCode: 20 изображений TOP внутри `[solid]` и отдельную GIF
над ними. Несмотря на расширение `.md`, это не Markdown для отображения на сайте.

## Как читать память

- `about:memory` может дать память по URL. В одном снимке изображения занимали
  около 368 МБ, или 71,6% явных выделений процесса. TOP — около 134 МБ,
  избранное — 69 МБ, достижения — 58 МБ, франшизы — 47 МБ, два фона — 39 МБ.
  Это снимок кэша, не вся память Firefox и не рейтинг CPU.
- Разделяй сжатые данные (`source`) и декодированные поверхности. Числа в квадратных
  скобках отчёта памяти не принимай без проверки за полное число кадров файла.
  Вложенные суммы отчёта нельзя складывать повторно с их дочерними значениями.

## Сохранённые результаты анализа кадров

- `.image-audit/` исключён из Git. Там находятся скачанные оригиналы, `inventory.json`,
  `downloads.json`, `results.json`, `report.md` и локальный анализатор `analyze.py`.
  Наличие этих файлов в следующем окружении не гарантировано; не публикуй их автоматически.
- Проверены 62 уникальных URL из основного CSS и `about.md`: 61 уникальный файл по SHA256,
  около 28,36 МБ скачанных копий, 2 609 кадров в учёте всех URL. Ошибок загрузки не было.
- Точных соседних повторов внутри циклов не найдено, в том числе после игнорирования
  RGB полностью прозрачных пикселей. Это не проверка на приблизительное сходство.
- У одной анимации совпали первый и последний кадры. Они не объединялись:
  такое изменение может сдвинуть начальную фазу и требует отдельной проверки времени.
- Анализ выполнялся по полным RGBA-кадрам после наложения и очистки. Новые версии
  изображений не создавались, ссылки и файлы на хостинге не менялись.
- Пользователь разрешил только сбор ссылок, скачивание копий и отчёт.
  Пересборка, загрузка оптимизированных версий и замена ссылок требуют нового согласования.

CSS `animation-play-state` не останавливает внутренние кадры GIF/WebP;
`content-visibility` не гарантирует освобождение кэша. CSS-масштабирование не
уменьшает скачиваемый файл. Контекст экспериментов — [performance.md](performance.md).
