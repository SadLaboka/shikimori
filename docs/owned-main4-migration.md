# Прямой импорт main4: подготовка

25 октября 2026 года. Main1 принят пользователем, его переключение и отчёт
сохранены отдельными локальными коммитами. Подготовлен последний модуль основы,
но main4 пока не отправлен в GitHub и не опубликован на Shikimori.
Основной CSS не менялся: SHA256
`d4595c298af199afe18a7c42707a2ed0c86ef8f3ae1a9a1e9d0fe02372c285ee`.

## Источник, правила и зависимости

`css/base/main_code_4mob.css` — побайтная копия
`vendor/edesign/main_code_4mob.css`: 131 543 байта, SHA256
`dcbd66b37e8580c4f47eead04f696e4f24801996cdb3ee41ef97839d20654e1d`.
Автор E-design / ed-main, upstream commit
`d54e91b58c7c16def6f73e7289e29f895a984195`. Авторство, комментарии, исходные
пробелы, изображения и их ссылки сохранены; новая лицензия не назначается.
Узкое исключение `blank-at-eol` применено только к собственной копии main4,
как ранее к vendor, чтобы сохранить хэш. Остальные файлы проверяются обычно.

Локальный commit модуля: `8912ca67ab5e4915c6ba9ea065f9ee609481ccd3`.
Будущий URL: `https://raw.githubusercontent.com/SadLaboka/shikimori/8912ca67ab5e4915c6ba9ea065f9ee609481ccd3/css/base/main_code_4mob.css`.

В Chromium: 227 правил верхнего уровня CSSOM, 816 с вложенными, 72 media-правила,
263 исходных вхождения `!important`, пять `url()`, без вложенных `@import`.
Условия включают ширину и portrait; используются десять переменных темы.
Название mobile не означает исключительно телефон: есть min-width для планшета
и desktop, адаптация профиля/шапки/меню/карточек, списков и общих компонентов.
Модуль зависит от остальной основы и пользовательских переопределений.

Кандидат `.preview/owned-main4-work/candidate.css` меняет только источник main4
на прежнем месте; порядок, специфичность, media, псевдоэлементы, `!important`,
значения и пересечения остаются прежними. Число импортов — шесть. Правила не
оптимизировались, существующие недостатки мобильного дизайна не исправлялись.

## Преобразования URL

Используется существующий механизм манифеста, без изменения логики Playwright.
Подтверждены пять правил с одним URL в каждом из `vendor/edesign-pins.json`:
две ссылки на ту же картинку moe.shikimori.one обёрнуты в наблюдаемый Camo,
два GIF dere.shikimori.one и картинка i.ibb.co раскрыты из `/x/…` в прямые URL.
Сверка привязана к индексам, хэшам CSSOM-правил, точным парам и числу вхождений;
неизвестные отличия отвергаются. Тело основы в предпросмотре сохраняется,
меняется лишь метка источника. Рабочий модуль не получает переписанных URL.
Это проверка эквивалентности существующего блока, а не эмуляция будущей компиляции.

## Ограничения и следующий шаг

LOCAL PASS, `remoteSourcesVerified: false`: новый commit-URL ещё не проверен.
После отдельного разрешения на push нужно проверить удалённый источник обычным
режимом, переключить основной CSS и повторить предпросмотр. Публикация Shikimori
требует своего разрешения, затем нужна сверка реально скомпилированного блока.

Все 72 media-ветки сохранены структурно; каждая граница и landscape отдельно
не прогонялись. Дополнительные ширины 767/768/1023/1024/1025 проверяют профиль,
а не все компоненты всего сайта. Каталог, меню во всех состояниях и редактор
не проверялись отдельно в реальном DOM. Отдельный `--check-history` не запускался.
Полный CSSOM подтверждает сохранение правил, но не заменяет визуальную оценку
каждой страницы. Firefox, авторизованный вид и реальные устройства не покрыты.
Перенос не обещает исправления мобильной версии или ускорения.

После успешной публикации main4 все четыре модуля основы будут загружаться из
своего репозитория. Два Google Fonts остаются внешними. Изображения и шрифты
не переносятся этим шагом. Обновления upstream требуют отдельного сравнения,
commit-URL не обновляется автоматически. Разбиение на компоненты и оптимизация
правил остаются отдельной последующей работой.
