# Изображения в GitHub · 0.3.4

Перенесены без перекодирования 77 оригинальных файлов: 70 личных изображений
схем и TOP и 7 ресурсов основы E-design. Источники, размеры и SHA256 записаны
в `assets/images/manifest.json`. Ссылки закреплены на коммиты, а не `main`.
Ранее размещённые в GitHub изображения схем остаются на прежних адресах.

`Dno-fon.jpg` (`https://i.ibb.co/tD9K2Lq/Dno-fon.jpg`) недоступен. По решению
пользователя файл пропущен, исходная ссылка в `main_code_4mob.css` сохранена.
Удалённый с сайта `bd.png` взят из истории официального репозитория Shikimori;
адрес оригинала записан в манифесте. Шрифты не переносились.

Три изменённых модуля основы связаны с прежними байтами в `css/image-assets.json`.
Проверка разрешает только перечисленные URL, включая ссылки внутри media;
любые другие изменения, даже обновление итогового хэша после удаления правила,
отклоняются. Исторические проверки vendor и оптимизаций сохранены; перед ними
отдельно проверяется точная обратимость переноса изображений.

```powershell
node scripts/verify-image-assets.mjs
node --test tests/image-assets.test.mjs
pnpm --dir tools/preview test
node scripts/build-css.mjs --check
node scripts/build-emerald-scarlet.mjs --check
node scripts/build-gold-jade.mjs --check
```

Предпросмотр понимает новые закреплённые модули через `tools/preview/image-assets.mjs`:
проверяет удалённые байты и CSSOM прежних блоков с известными преобразованиями
компилятора. Неизвестные импорты и перестановки по-прежнему отклоняются.
Серверная обёртка расширения с седьмым импортом полного CSS не равна шести
импортам исходной сборки: обычный строгий прогон их не подменяет автоматически.

Локальный отчёт переноса: `.preview/github-images/report.json` и снимки рядом.
Проверены CSSOM всех правил основы и схем, вычисленные стили и геометрия
публичного DOM профиля: шесть вариантов на ширинах 1440, 390 и 360 px.
Запросы изображений в этом сравнении обслужены проверенными оригиналами;
это не проверка доступности GitHub. Адреса GitHub проверяются отдельно.
Проверены 82 удалённых адреса изображений и CSS: HTTP 200 и точный SHA256;
результат записан в `.preview/github-images/remote.json`.
Динамика кадров сохраняется побайтной идентичностью файлов.
Отсутствующие на публичном профиле служебные блоки основы не имеют покрытия
состояний; для них подтверждено только сохранение правил и содержимого картинок.
Строгий прогон живого профиля остановлен защитой от изменения структуры импортов
(7 импортов серверной обёртки против 6 импортов полной схемы); он не объявлен PASS.

Изменение репозитория и выпуск расширения не публикуют CSS или BBCode
на Shikimori. Новые адреса активируются при применении схемы из обновлённого
расширения; TOP из `about.md` устанавливается отдельно.
