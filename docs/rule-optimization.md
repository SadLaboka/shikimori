# Первая оптимизация собственных правил

25 октября 2026 года. После завершения переноса источников выбран небольшой
блок без изменения дизайна: `animation_border_left`, `animation_border_right`,
`glow-animation` в `styles_optimized.css`. Одинаковые объявления 0% и 100%
объединены в `0%, 100%`; значения, длительности, задержки и средние кадры сохранены.
Импорты, рабочая основа, изображения, цвета и остальные правила не менялись.

Размер основного файла: 57 261 → 57 053 байта, удалено 11 строк/208 байт.
Это устранение повторов, а не подтверждённое ускорение отрисовки. Простых
повторных объявлений внутри собственных блоков предварительный поиск не обнаружил.
`transition: all`, старые ошибки синтаксиса и мобильные дефекты не исправлялись попутно.

## Проверка

Обычный предпросмотр выполнен на 1440/390/360:
[отчёт и снимки](../.preview/2026-10-25T15-24-36-414Z/index.html).
Измеряемые стили и геометрия совпали, но строгий миграционный вердикт — **FAIL**:
`exactPosterCascade` и `unchangedNonLayoutCascade` требуют одинакового CSSOM.
Перегруппировка кадров меняет его запись. Исходный FAIL сохранён, защиты не изменены.

Для этой конкретной оптимизации выполнена отдельная целевая проверка:
[HTML и снимки](../.preview/rule-opt-work/index.html),
[данные и покрытие](../.preview/rule-opt-work/equivalence.json),
[локальный проверочный сценарий](../.preview/rule-opt-work/check.mjs).
Кандидат, baseline и материалы остаются в игнорируемой `.preview/`.

- Полный разобранный CSSOM совпадает после **только** разворачивания групп
  процентов трёх указанных keyframes в отдельные offsets. Никакие остальные
  правила или декларации из сравнения не исключаются. Все три имени присутствуют
  ровно по одному разу. Неизвестное отличие остановило бы проверку.
- Отрицательный контроль: изменение background-position одного кадра
  обнаруживается этим сравнением.
- 21 случай: 1440/390/360 × фазы 0, 0.125, 0.25, 0.5, 0.75, 0.875, 1.
  Сравнивались прямоугольники, все вычисленные свойства целевых узлов и
  `::before`/`::after`, WAAPI keyframes и timing. Изменений нет.
- Заголовки `.subheadline` проверены на настоящем профиле. Реальных редакторов
  `.comment_body textarea` в анонимном DOM — ноль; для `glow-animation` использован
  явный fixture с textarea и фокусом. Это проверка эффекта, не авторизованной формы.
- Целевые снимки заголовка до/после просмотрены на трёх ширинах. Оформление и
  геометрия совпадают; на мобильных снимках видны меняющиеся кадры соседней GIF.
- Во время проверки снимков исправлен путь Windows с кириллицей в локальном
  сценарии; после исправления весь целевой прогон выполнен успешно.

Итог — **PASS целевой эквивалентности трёх анимаций**, а не общий PASS миграционного
аудита. Основной CSS заменён только после проверки совпадения хэша кандидата
с сохранённым входом предпросмотра. SHA256:
`78214680d782896b0d21682dc3cd8e0bc269f8347c0d5336856cb0feda64b322`.
Повторный миграционный прогон для тех же байтов не запускался: он дал бы тот же FAIL.

Firefox, реальные телефоны и редактор после авторизации не проверены. CPU/GPU
не измерялись; GIF/WebP не заморожены. Первоначальные проверки не публиковали CSS.

## Публикация

25 октября по отдельному разрешению выполнены dry-run, backup и один PATCH
штатным deploy. Повторный GET подтвердил SHA256 проверенного кандидата.
[Проверка серверного результата](../.preview/2026-10-25T15-44-58-896Z/index.html):
PASS на 1440px, модель CSSOM совпала с серверным результатом; опубликованная
запись объединённых кадров сохранена. Здесь baseline уже опубликован после
оптимизации: этот PASS не заменяет первоначальное сравнение с прежними кадрами.
Целевая эквивалентность до/после по-прежнему доказана отдельными 21 случаями выше.
Визуальная проверка пользователя ожидается. Push не выполнялся.

## Skill для будущих правок

Создан `.agents/skills/shikimori-css-design/SKILL.md` с UI-метаданными.
Он выбирает документы и проверки по компоненту, отделяет дизайн от миграции,
не загружает все старые отчёты и не требует повторения успешных прогонов без причины.
Короткая памятка об ограничениях инструментов — [design-workflow.md](design-workflow.md).

Проверены frontmatter, имя, UI-строки, относительные ссылки и отсутствие заготовок.
Штатный `quick_validate.py` не запустился из-за отсутствующего PyYAML; новые
зависимости ради него не устанавливались. Структура проверена отдельно.
Реальная проверка анимаций выше служит примером выбора целевых проверок;
отдельное независимое испытание Skill другим агентом не проводилось.
