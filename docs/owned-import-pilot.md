## Как подключать

1. Отдельный commit с модулем уже создан. После разрешения отправить его в GitHub.
2. Проверить реальный URL и SHA256. Не подменять недоступный ответ локальным файлом.
3. Заменить только URL main3 на прежнем месте в списке импортов и проверить кандидат
   обычным предпросмотром без `--local-imports`.
4. После успешной проверки обновить основной CSS; публикация в Shikimori требует
   отдельного разрешения. Затем проверить серверный скомпилированный результат.

Разделение коммитов позволяет ссылаться на уже существующий SHA: файл со ссылкой
на модуль появляется после коммита самого модуля. Вложенные импорты и сборщик
не нужны. Новый commit рабочего модуля сам по себе не обновляет профиль.

## Локальный предпросмотр до push

`css/imports.json` разрешает одну точную пару исходник → свой commit-URL.
Предпросмотр проверяет SHA256 snapshot, рабочего файла и содержимого Git-коммита;
затем сверяет CSSOM модуля с опубликованным блоком. Меняется только метка источника
на прежнем месте основы. Это допустимо именно для побайтно одинакового переноса;
изменения правил этим механизмом не разрешены.

Флаг `--local-imports` явно отключает удалённую проверку своего модуля.
Вердикт — **LOCAL PASS**, `remoteSourcesVerified: false`. Остальные внешние
источники по-прежнему проверяются по сети. Обычный режим требует GET своего
commit-URL, проверяет хэш и при ошибке останавливается без локального fallback.

В main3 нет вложенных `@import`. Четыре URL ресурсов сохранены: путь
`/assets/blocks/b-video_variant/bd.png`, абсолютная картинка i.ibb.co и два
fonts.gstatic.com. При наблюдаемом серверном разворачивании корневой путь остаётся
относительным к Shikimori; совпадение с нативным браузерным `@import` не заявляется.
Новую обработку URL сервером после переключения ещё предстоит проверить.

Как и нынешний upstream commit-URL, свой commit-URL не получает обновления
автоматически; сравнение новых upstream-версий остаётся отдельной задачей.
Другие три модуля E-design пока не скопированы в рабочую основу; шрифты по решению
пользователя остаются внешними импортами.
