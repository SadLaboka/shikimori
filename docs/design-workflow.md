# Проверка изменений дизайна

Проектный Skill: `.agents/skills/shikimori-css-design/`. Для переноса источников
по-прежнему используется отдельный migration Skill. Сначала выбирай целевые
селекторы, страницу, состояния и свойства; потом — достаточные проверки.
Пути и основные команды: [preview.md](preview.md).

## Что умеет существующий предпросмотр

`--css` заменяет пользовательский стиль, сохраняя проверенную основу. Поддержаны
страницы `--component profile|history`, ширины `--widths 1440,390,360`.
`--url` отсутствует. Фильтры, каталог и другие страницы требуют отдельного
целевого прогона имеющимся Playwright на настоящем DOM. Не подменяй это
проверкой похожего узла профиля или одним синтетическим примером.

`--check-layout`, `--check-history`, `--check-activity`, `--check-posters`
созданы для миграционной эквивалентности. В частности, полный CSSOM и хэши
правил обязаны оставаться прежними. Изменённый цвет, перегруппированный keyframe
или селектор могут дать FAIL при корректном дизайне. Не удаляй эти проверки.
Сохраняй отчёт, разбирай конкретные флаги; целевая проверка должна подтвердить
только ожидаемые отличия и отсутствие остальных регрессий. Общий FAIL не становится
общим PASS от комментария «это дизайн».

## Как выбирать проверку

- Анализ/документация: поиск и статическая сверка; браузер без нужды не запускать.
- Изменение вида: замена всего стиля, целевые узлы и псевдоэлементы, состояния,
  ожидаемые свойства, геометрия; просмотр целевых снимков до/после на трёх ширинах.
- Оптимизация без смены вида: доказательство семантической эквивалентности,
  вычисленные стили и поведение. Для анимаций сравнивать фазы, keyframes и timing.
  Нельзя игнорировать целые правила ради зелёного результата.
- Смена условий media: проверять обе стороны изменённой границы; существующие
  дефекты мобильной версии отделять от новых изменений.
- Правка инструментов: соответствующие тесты и отрицательный контроль.

При отсутствии узла явно отметь непроверенное состояние. Fixture может проверить
отдельное правило, но не доказывает его работу в авторизованном интерфейсе.
CSS-анимации в обычном снимочном прогоне остановлены; GIF/WebP продолжают менять
кадры. Изучай сводку прежде изображений, не открывай автоматически все отчёты.

Изменение `css/base/` не обновляет закреплённый URL и сейчас отклоняется проверкой
vendor-хэша. Для такой задачи сначала нужен отдельный механизм кандидата и новая
версия источника; обычные правки выполняются поверх основы в основном CSS.
