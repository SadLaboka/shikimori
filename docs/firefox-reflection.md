# Отражение надписей в Firefox

В `styles_optimized.css` добавлен отдельный `@supports` для Gecko без
`-webkit-box-reflect`. Используются абсолютно позиционированные псевдоэлементы,
`scaleY(-1)` и градиентная маска. Декоративная копия не участвует в раскладке,
не перехватывает указатель и имеет пустой альтернативный текст.

Логотип повторяет исходную анимацию; остальные копии наследуют текущие цвет
и тень текста. Отражение кнопки входа берёт надпись из `data-text` и действует
от 1024px: ниже сайт показывает иконку вместо текста. Логотип отражается также
на мобильных ширинах. Chromium продолжает использовать прежний box-reflect.

У заголовка раздела и никнейма нет атрибута с их текстом на самом span.
Поэтому русские подписи разделов перечислены по классам меню, а SadLaboka
включён только рядом с аватаром с соответствующим `alt`. Другие имена и
неперечисленные подписи остаются без отражения: чужой текст не подставляется.
Изменение имени или локализации потребует дополнить эти правила.
`-moz-element()` не подходит для этих узлов: у них нет ID.

Проверено 25 октября 2026 года в Playwright Firefox 157 и Chromium:

- Настоящий публичный профиль: 1440, 1024, 1023, 390 и 360px.
- Настоящие каталог аниме и форум с временной подстановкой темы: 1440px.
- Обычный вид, hover, focus, раскрытое меню, фазы анимации 0 и 150ms.
  На мобильном использована видимая штатная кнопка меню.
- Геометрия, шрифт и параметры анимации целевых надписей не изменились.
  В Chromium также сохранилось содержимое их псевдоэлементов.
- Просмотрены снимки Firefox на 1440, 390 и 360px и светящаяся фаза каталога.
- Авторизованный никнейм проверен только на локальной модели публичного
  шаблона сайта: цвет и тень отражения совпадают с оригиналом; другое имя
  не получает отражение SadLaboka. Реальный вход в аккаунт не выполнялся.

Остальные перечисленные разделы не проверены на реальных страницах.
Материалы проверки находятся в игнорируемой `.preview/firefox-reflection/`.
Снимки не являются попиксельной гарантией: фон содержит анимированные изображения.
CSS опубликован через scripts/deploy.ps1 с резервной копией; серверный css совпал с проверенным SHA256. После публикации настоящий профиль открыт в Firefox на 1440px без подстановки CSS: у логотипа, SadLaboka и входа подтверждены текст отражения, маска и переворот. Материалы: .preview/firefox-reflection/published.json и published-firefox.png.
