# Удаление раннего радиуса main3

Из `css/base/main_code_3.css` удалено только `border-radius: 0px` в раннем
безусловном `.l-page` (24 байта). Три других свойства блока сохранены.
Поздний безусловный `.l-page { … border-radius: 8px; }` имеет ту же
специфичность и перекрывал раннее объявление. Media, псевдоэлементы,
`!important`, остальные правила и их порядок не менялись.

SHA256 кандидата и рабочего файла:
`934345f04217e7e01252d5a36bea6430f0a328dd230ab8acf2559fd087a87053`.
На локальном этапе vendor, manifest импортов, основной CSS и опубликованный URL
оставались прежними; последующее подключение описано в конце документа.
Ускорение от удаления одной строки не измерялось и не обещается.

## Предпросмотр

```powershell
node tools/preview/preview.mjs --check-layout --widths 1440,390,360
node tools/preview/preview.mjs --component history --check-history --widths 1440,390,360
node tools/preview/preview.mjs --component catalog --widths 1440,390,360
```

До подключения новой версии использовался `--main3-radius-candidate <file>`.
Флаг допускает только точное побайтное удаление выбранной строки из проверенного
vendor. Сверяются опубликованные модули и их remote SHA; в main3 заменяется
только этот блок внутри прежней метки источника. Полный CSSOM должен отличаться
ровно одним объявлением, с прежним числом правил. Остальные изменения запрещены.
Примесь других правок пользовательского CSS/импортов, replay и сочетание пилотов
отклоняются. Рабочий main3 может отличаться от vendor только этой точной правкой
при явном флаге или отдельном разрешении версии `css/main3-optimization.json`;
обычный owned-import путь продолжает отклонять изменённую основу.

Исходный строгий миграционный FAIL сохраняется: CSSOM намеренно изменён.
`LOCAL RADIUS PASS` относится к этой конкретной оптимизации и реальному `.l-page`,
а не к непроверенной кнопке main1. Неизменённые состояния кнопки не повторяются.
Ноль реальных `.l-page` не даёт PASS. Публикация новой версии потребует отдельного
commit-URL и проверки его серверной компиляции; текущий флаг ничего не публикует.

### Обнаруженная проблема измерений

Первые прогоны каталога дали FAIL на 1440: менялись сообщаемые браузером
автоматические отступы и дробная высота внешнего контейнера. Карточки/фильтры
и радиус совпадали. Контроль A/A с одинаковым CSS воспроизвёл `120px → 0px`
в resolved margins при неизменных координатах — это не влияние удалённой строки.
Простой повтор и дополнительный прогрев проблему не устранили, эти FAIL сохранены.

Пилот каталога теперь сравнивает свежие документы для обеих фаз, устраняя
зависимость высоты от истории вкладки. Для внешнего `.l-page` сравнивается
вычисленное Typed OM значение `auto`; сырые resolved margins остаются отдельно
в `state.rawResolvedPageMargins`. Реальное положение/размеры строго сравниваются
по rect; фиксированные отступы не нормализуются. Отрицательный тест подтверждает,
что замена auto на 10px и реальный сдвиг обнаруживаются. Сравниваемые свойства
не исключались, допуски для геометрии не вводились.

Негативные проверки также отклоняют посторонние байты, потерянное позднее
правило радиуса и дополнительное CSSOM-правило. Внешний вид в Firefox,
авторизованном интерфейсе и на физических телефонах не проверен.

## Подключение новой версии

По отдельным разрешениям пользователя модуль запушен коммитом
`8fc0b68fa3578b6e8a3884dbb23651d86d885f73`, затем его закреплённый URL
подключён в основном CSS. Остальные импорты не менялись.
`css/main3-optimization.json` разрешает только старый → новый URL и проверенный SHA.
Предпросмотр проверяет точные байты рабочего файла и удалённого ответа;
до публикации заменяет только этот блок и метку, после — сверяет весь новый
серверный CSSOM. Vendor и исходный manifest остаются эталонами.

Добавлены отрицательные тесты чужих repo/path/hash и посторонних изменений
импортов/пользовательских правил; итог **48/48**. Уже успешные состояния
и мобильные ширины тех же байтов повторно не запускались.
[Удалённый URL перед публикацией](../.preview/2026-10-25T20-24-29-200Z/index.html)
проверен на 1440px: LOCAL RADIUS PASS.

Компактный deploy сохранил backup, показал только замену URL (+1/−1 строка),
получил подтверждение и выполнил один PATCH с GET-сверкой. Серверный SHA256:
`948e1abbbdc3d585b5f269ce2cc052384d36a43939c7d0fca5d4f1abfb6ff8c4`.
[После публикации](../.preview/2026-10-25T20-26-34-742Z/index.html): новая метка
источника и весь серверный CSSOM совпали с моделью; строгие инварианты PASS,
целевой статус LOCAL RADIUS PASS. Скругления и геометрия на 1440px не изменились.
