## Исправленные проблемы синхронизации

Прокрутка к футеру запускала новые страницы: число карточек между снимками
менялось. Для каталога убрана такая разминка и блокируется только пагинация 2+.
Независимые рекламные скрипты исключены, чтобы popup не перекрывал мишени.

После выбора новый анонимный документ очищает `style#custom_css`: теперь тема
повторно устанавливается в реальный slot после GET, а сброс во время снимка — ошибка.
Применение фильтра отслеживается после закрытия dropdown, не после одного клика
пункта. Клик по выбранному chip не используется для закрытия: он меняет знак выбора.

При одинаковом CSS Chromium сохранял старое положение float/margin и давал 5px
сдвиг карточек. Для обеих подстановок добавлен симметричный сброс кэша раскладки
до измерений. Допуски не увеличены. Внешняя высота страницы и динамическая
пагинация находятся вне заявленной области, проверяются сетка и целевые узлы.
Ожидание URL ограничено; несработавший интерактивный сценарий завершается ошибкой.

## Совместимость и ограничения

Существующие режимы прошли контроль:
[профиль, 1440](../.preview/2026-10-25T16-27-05-017Z/index.html),
[история, 390](../.preview/2026-10-25T16-27-05-039Z/index.html).
Их защиты не ослаблены. Новые офлайн-примеры проверяют инструменты;
они не выдаются за реальную страницу, в живом прогоне fixtures не используются.

Проверяется первая страница каталога, без рекламы и дальнейшей подгрузки.
Полный снимочный проход сверяет все вычисленные свойства узлов карточек/фильтров;
сценарии состояний — геометрию и 47 перечисленных в JSON свойств с псевдоэлементами,
включая первые три карточки. Это не проверка каждого CSS-свойства во всех состояниях.

Поиск внутри списков, их прокрутка, исключение/сброс, удаление chip, все комбинации,
клавиатурная навигация по option, Firefox, авторизованные списки и настоящие
телефоны не покрыты. Focus проверяется у настоящего контрола, это не аудит
доступности. GIF/WebP не заморожены; pixel diff остаётся диагностическим.
Все HTML/JSON/снимки и временный CSS хранятся в игнорируемой `.preview/`.
