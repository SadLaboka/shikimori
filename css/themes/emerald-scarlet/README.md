# Emerald & Scarlet

Отдельная цветовая схема под Зоро **слева** и Шанкса **справа**.
Основная тема `styles_optimized.css` и её компоненты не изменяются.

Графитовые поверхности `#0e1312`, светлый текст `#d3ded8`, изумрудные
ссылки `#5bdc9b`, алый акцент `#f4475d` и светлый коралловый hover `#ff6b7c`.
Зелёный ведёт ссылки, аниме и свечение меню; красный — мангу, вторую сторону
рамок и активные состояния. Палитра действует на всём сайте, где применяется тема.
Сохранены геометрия, шрифты, длительности анимаций и существующие изображения.
Для картинок никнейма и TOP/TIERLIST подготовлены отдельные перекрашенные
[анимированные WebP](assets/README.md). Загруженные пользователем версии
подключены только в этой схеме: логотип через `background-image`, TOP/TIERLIST
через `content` существующего изображения в ссылке на конкретный тирлист.
Общий `about.md` сохраняет исходный адрес для основной темы.

## Переключение

Используются два **полных** взаимоисключающих файла:

- Основная схема: корневой `styles_optimized.css`.
- Альтернативная: `css/themes/emerald-scarlet/styles.css`.

Для переключения заменяется весь CSS выбранным файлом. Для возврата используется
корневой файл. Не добавлять альтернативу поверх уже установленной темы: это
дублирует импорты и правила. Переключатель на странице не требуется; HTML и JS
Shikimori не меняются. Альтернативная тема опубликована 27 октября 2026 года
по разрешению пользователя; git push не выполнялся. Следующие публикации
и push требуют отдельного разрешения.

## Исходники и сборка

`palette.css` содержит переменные и фон. `colors.json` переводит жёстко заданные
цвета собственных компонентов (свечение, рамки и скроллбар). Основные исходники
общие для обеих схем, поэтому исправления раскладки не приходится дублировать.
Сборка не меняет `@import`, URL, alpha, интервалы анимаций, основу и оригиналы.
Старые синтаксические особенности общих компонентов сохраняются.

Из корня репозитория:

```powershell
node scripts/build-css.mjs --check
node scripts/build-emerald-scarlet.mjs --candidate
node tools/preview/preview.mjs --css .preview/emerald-scarlet/candidate.css --widths 1440,390,360
node tools/preview/preview.mjs --css .preview/emerald-scarlet/candidate.css --component catalog --check-filters --widths 1440,390,360
# После проверки именно этих байтов кандидата:
node scripts/build-emerald-scarlet.mjs --write
node scripts/build-emerald-scarlet.mjs --check
node --test tests/build-css.test.mjs tests/emerald-scarlet.test.mjs
```

`--write` сверяет результат с кандидатом и пишет только альтернативный `styles.css`.
После изменений общих компонентов пересобирать и проверять обе схемы отдельно.
Обычная сборка/публикация основной темы альтернативу не выбирает.

Миграционные проверки требуют одинакового CSSOM и одинаковых вычисленных цветов,
поэтому намеренная смена палитры даёт строгий FAIL. Его нельзя считать PASS:
для дизайна отдельно сверяются ожидаемые цвета и неизменность остальных свойств.
Снимки и полные локальные отчёты находятся в игнорируемой `.preview/`.

Проверено 27 октября 2026: Chromium, профиль и каталог на 1440/390/360 px;
503 узла профиля с псевдоэлементами, 30 состояний реальных фильтров
(открытие, hover, focus, active, выбор), граница фона 1279/1280 px и
композиция на 2560 px. Геометрия сохранена; целевая проверка отличий
обнаружила только свойства палитры. Строгие миграционные FAIL сохранены.
Отдельно проверены цвета ссылки при hover/focus, фокус поиска и зелёные
кадры анимации меню с прежней длительностью 6 секунд. Firefox, настоящий
телефон и редактор комментария под авторизацией не проверены.
