# Gold & Jade · Улькиорра и Йоруичи

Самостоятельная золотая и бирюзовая схема Shikimori. Выбран вариант **2.2**:
Улькиорра слева зеркальный, новая Йоруичи справа без отражения. Акценты интерфейса
идут наоборот относительно персонажей: золотой слева, бирюзовый справа.

## Установка и возврат

Готовый полный файл — [styles.css](styles.css). Он побайтно совпадает с
[проверенным вариантом 2.2](variants/2-2/styles.css).

Замени весь пользовательский CSS содержимым этого файла. Две полные схемы
не накладываются друг на друга. Для возврата используй корневой
[styles_optimized.css](../../../styles_optimized.css) или полный
[Emerald & Scarlet](../emerald-scarlet/styles.css).
Серверный backup нужен для возврата к точному ранее опубликованному состоянию,
которое может отличаться от основной темы.

Gold & Jade доступна полным CSS и в [Firefox-переключателе](../../../extensions/firefox/),
в цикле «Основная → Emerald & Scarlet → Gold & Jade → Основная». Наличие файлов в GitHub само по себе не
меняет оформление профиля. Публикация — по [порядку выпуска](../../../docs/release.md),
с явным путём к файлу и проверенным SHA256.

## Оформление и ресурсы

Золото — `#ffd842`, бирюза — `#3bebc0`. Текст светлый нейтральный,
поверхности почти чёрные. Логотип Shikimori и левое меню используют золотой
акцент, Вход / меню профиля справа — бирюзовый. Цвет свечения следует той же
стороне; тайминги анимаций и геометрия блоков сохранены.

- Йоруичи: [исходный WebP](assets/yoruichi.webp), [прямая ссылка](https://raw.githubusercontent.com/SadLaboka/shikimori/fb5a29b76c26de5b3a2568e8294a848dd3b57c0a/css/themes/gold-jade/assets/yoruichi.webp).
- Улькиорра: <https://res.cloudinary.com/dostk7gvx/image/upload/v1793533871/ulquiorra-v12-10mb_qilfw7.webp>.
- SadLaboka v2: <https://res.cloudinary.com/dostk7gvx/image/upload/v1793540958/sadlaboka-gold-jade-v2_h02zoe.webp>.
- TOP/TIERLIST: <https://res.cloudinary.com/dostk7gvx/image/upload/v1793540775/top-tierlist-gold-jade_znyitc.webp>.
- Верхняя полоса центра: [header-bridge-1180x100-optimized.webp](assets/header-bridge-1180x100-optimized.webp),
  1180 × 100, 200 кадров, 8 секунд, 3 619 042 байта. Исходный файл сохранён
  без перекодирования; URL закреплён коммитом `10285d94bd3e6a09b25c939a8f053f80c5bac27d`.
  Полоса включается вместе с боковыми фонами от 1280 px, повторяет ширину
  центра с нахлёстом, сохраняет пропорции и плавно затухает по бокам и снизу.

Фоны включаются от 1280 px и остаются по краям окна. На широких экранах
их ширина заполняет пространство до центральной страницы шириной 1200–1800 px
с запасом под затухание. `cover` сохраняет пропорции изображений; при увеличении
ширины часть изображения может обрезаться сверху и снизу. На обычных экранах
сохраняется прежний размер по высоте.
Только внутренние края плавно затухают: `clamp(24px, 4.5vh, 64px)`.
Две независимые CSS-маски сохраняют эффект при перекрытии изображений.
Фоновые WebP не перекодированы; отражение и затухание выполняются через CSS.

SadLaboka и TOP/TIERLIST перекрашены покадрово с сохранением альфы, числа кадров,
каждой длительности и цикла. У SadLaboka v2 справа убрана золотистая примесь;
TOP/TIERLIST использует точные акценты темы. [Готовые файлы и параметры](assets/README.md).
У анимации над аватаром только пол перекрашен в золотой цвет Йоруичи;
белые фигурки, прозрачность и все 63 кадра сохранены. Остальные изображения сохранены.

Файлы Cloudinary и GitHub побайтно совпадают с проверенными локальными.
Новая Йоруичи сохранена без перекодирования и отображается без отражения.
Ссылка на файл закреплена коммитом.

## Сборка

Источники — общие компоненты основной темы, замены цветовых литералов в
[scripts/build-gold-jade.mjs](../../../scripts/build-gold-jade.mjs),
общая [palette.css](palette.css) и [правила выбранной 2.2](variants/2-2/overrides.css).
Цвета, layout, изображения и импорты Emerald & Scarlet не наследуются;
используется только её функция замены цветовых литералов.

Из корня репозитория:

```powershell
# По умолчанию выбран вариант 2.2.
node scripts/build-gold-jade.mjs --candidate
# Проверить .preview/yoruichi-ulquiorra/2-2/candidate.css в браузере.
node scripts/build-gold-jade.mjs --write
node scripts/build-gold-jade.mjs --check
node --test tests/gold-jade.test.mjs
```

`--write` требует совпадения сборки с кандидатом и записывает одинаковые байты
в `styles.css` и `variants/2-2/styles.css`. `--check` проверяет оба файла.
Корневой CSS основной темы и остальные схемы не изменяются.

| Вариант | Слева / справа | Акценты слева / справа | Полный CSS |
| --- | --- | --- | --- |
| 1.1 | Йоруичи / Улькиорра, исходная ориентация | Золото / бирюза | [styles.css](variants/1-1/styles.css) |
| 1.2 | Йоруичи / Улькиорра, исходная ориентация | Бирюза / золото | [styles.css](variants/1-2/styles.css) |

| **2.2** | **Улькиорра зеркальный / новая Йоруичи без отражения** | **Золото / бирюза** | [styles.css](styles.css) |

1.1, 1.2 и 2.1 сохранены как варианты для сравнения. Новые размещённые анимации
и затухание подключены только в 2.2; у остальных для баннера и TOP/TIERLIST
действует исходный fallback. Другой номер выбирается флагом `--variant`.

## Проверки и ограничения

Замена правого фона на `yoruichi-claw-discharges-no-vapor.webp` проверена
сборкой и просмотром diff; перечисленные ниже визуальные проверки относятся
к предыдущему фону.

Выбранный CSS проверен в Chromium на настоящем публичном профиле:
2560×1440, 1920×1080, 1440×1080, 1280×1080, 1279×1080,
1280×1440 с перекрытием фонов, 390×844 и 360×844. Геометрия блоков совпала
с версией без затухания. Проверены вычисленные размеры, маски, ресурсы и
непрозрачность вне узкого перехода. Отдельная синтетическая проверка измеряет
плавное падение непрозрачности у обоих внутренних краёв.

Для трёх элементов шапки проверены цвета и свечение на фазах 0 / 300 / 2000 мс,
а также мобильные цвета. Проверены hover/focus и три фазы бегущей рамки.
На снимках CSS-анимации остановлены в начальной фазе; GIF/WebP продолжают
воспроизводиться, поэтому кадры на снимках могут различаться.

Десять тестов сборки проверяют исходную основу, импорты и URL, альфу и тайминги
исходного CSS, соответствие акцентов сторонам, неизменность прежних схем и
совпадение самостоятельной схемы с выбранной 2.2. Файлы не содержат локальных
путей или адресов тестового предпросмотра.

Штатный предпросмотр остановился на несовпадении способа подключения основы:
сервер дополнительно импортирует старый полный CSS. Отдельная целевая проверка
подтвердила модель серверного CSSOM и сохранила шесть импортов основы, заменив
старые собственные правила полной схемой только в памяти тестового браузера.
Это проверка дизайна, а не миграционный аудит или проверка публикации.

Авторизованный никнейм, другие страницы сайта и серверная обработка
новых URL/Camo не входят в визуальное покрытие. CSS на Shikimori не публиковался.
Снимки и полные отчёты хранятся локально в игнорируемой
`.preview/yoruichi-ulquiorra/`, в том числе `fade/report.json` и `hosted/verification.json`.

Адаптация для 4K (2 ноября 2026): на реальном публичном DOM профиля с текущими
локальными модулями основы проверены 3840×2160, 2560×1440, 1920×1080,
1440×900, граница 1279/1280 px и 390×844. Изменён только блок фоновых
псевдоэлементов; геометрия страницы и шапки, маски, URL и отражение сохранены.
Прокрутка и фаза анимаций не меняют положение фонов. Просмотрены снимки
до/после на 4K, Full HD и мобильной ширине. Изображения брались из локальных
файлов репозитория; серверная сборка и другие страницы этим прогоном не покрыты.
Штатный предпросмотр остановлен защитой от несовместимых импортов.
Материалы: `.preview/wide-background/`, сценарий `.preview/check-wide-background.mjs`.

Общее расширение профиля и сетки TOP для всех схем проверено отдельно:
[адаптация широких экранов](../../../docs/wide-layout.md). От 2560 px центр
плавно расширяется до 1800 px на 4K; сетка сохраняет четыре колонки и пять строк.
Сохранённые варианты 1.1, 1.2 и 2.1 также пересобраны с общей адаптацией.

Верхняя полоса центра (2 ноября 2026): целевая проверка Chromium на реальном
публичном профиле с локальными модулями основы и изображениями репозитория —
3840×2160, 2560×1440, 1920×1080, 1440×900, 1280×900, 1279×900,
390×844 и 360×844. Проверены загрузка полосы, пропорции, маски, положение
при прокрутке и отсутствие изменений геометрии страницы, меню и боковых фонов.
Просмотрены снимки Full HD, 4K и мобильной ширины. CSSOM прежних правил
совпадает после исключения единственного добавленного `.l-page::before`.
Штатный предпросмотр сохранил ошибку несовместимых импортов; целевой PASS
не означает миграционный PASS. Firefox, другие страницы и обработка URL/Camo
сервером не проверены. Публикация на Shikimori не выполнялась.
Локальные материалы: `.preview/header-bridge/report.json` и снимки рядом;
сценарий `.preview/check-header-bridge.mjs`.

Исправление наложения верхней полосы (2 ноября 2026): полоса перенесена
из `.l-page::before` в `html::before`. У `.l-page` собственный stacking context
с `z-index: 1`, поэтому отрицательный индекс дочерней полосы не помещал её
под боковые фоны. Теперь корневая полоса имеет `z-index: -2`, боковые фоны —
прежний `-1`. Изображения и размеры боковых фонов сохранены.
Целевой прогон Chromium и Firefox проверил десять размеров: 3840×2160,
2560×1440, 2559×1440, 1920×1080, 1600×900, 1440×900, 1280×900,
1279×900, 390×844, 360×844, а также прокрутку и фазы анимаций.
Просмотрены снимки; отдельная проверка контрольных цветов на реальном DOM
подтвердила перекрытие центральной полосы обоими боковыми фонами на четырёх
ширинах и воспроизвела ошибку старой версии. Отчёты и снимки:
`.preview/bridge-underlay-chromium/`, `.preview/bridge-underlay-firefox/`;
сценарии `.preview/check-bridge-underlay.mjs`, `.preview/check-bridge-layer-pixels.mjs`.
Модули основы и изображения подставлялись локально; обработка CSS сервером
и авторизованный вид не проверены, на Shikimori исправление не публиковалось.
