# Shikimori · SadLaboka

Личный репозиторий оформления моего [профиля Shikimori](https://shikimori.io/SadLaboka).
Здесь хранятся CSS, содержимое «Обо мне», история изменений и инструменты для проверки
и публикации оформления.

## Оформление

Тёмная тема с синими и малиновыми акцентами, свечением и анимированными изображениями.
Под себя настроены фон, меню, блок TOP, избранное, достижения, график активности,
списки и фильтры. CSS затрагивает и другие страницы Shikimori, где применяется мой стиль.

Оформление построено на E-design и CSS-club с собственными переопределениями.
Основа перенесена в репозиторий, четыре файла E-design подключаются по закреплённым
commit-URL, шрифты остаются внешними. Собственные правила разделены на компоненты,
включая готовую мобильную версию; [устройство CSS](docs/components.md).

## Как ведётся работа

Изменения сначала проверяются локально: предпросмотр временно подставляет CSS
в браузере без сохранения на Shikimori. Сравниваются снимки, размеры элементов
и вычисленные стили на ширинах 1440, 390 и 360 px. При переносе импортов дополнительно
проверяются каскад, дубли правил и затронутые состояния элементов.

Публикация — отдельный шаг с резервной копией и подтверждением. Push в GitHub
сохраняет историю проекта, но сам по себе не обновляет CSS профиля.

Собственные правила теперь редактируются в `css/components/`. Сборка кандидата:
`node scripts/build-css.mjs --write --output .preview/candidate.css`.
После проверки — `node scripts/build-css.mjs --write`; проверка актуальности —
`node scripts/build-css.mjs --check`. [Устройство компонентов](docs/components.md).
Локальные настройки, секреты, снимки и отчёты проверок в Git не входят.

- [Предпросмотр](docs/preview.md) — команды запуска, сравнение и ограничения проверок.
- [Публикация](docs/deployment.md) — настроенный процесс через PowerShell и API.

Приоритет — сохранить внешний вид при постепенном упрощении CSS и снижении нагрузки.
Мобильная версия пока требует отдельной работы; её проверка при переносах нужна,
чтобы замечать новые регрессии, и не означает, что адаптация уже готова.
