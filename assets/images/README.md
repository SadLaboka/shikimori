# Изображения личных схем

Оригинальные файлы оформления SadLaboka и TOP, перенесённые с внешнего хостинга
без перекодирования. Имена файлов — SHA256 содержимого. `manifest.json` связывает
исходный URL, путь, размер и контрольную сумму; одинаковое содержимое можно
проверить независимо от адреса хостинга.

CSS использует прямые ссылки `raw.githubusercontent.com` на фиксированный коммит.
Ранее добавленные изображения в `css/themes/*/assets/` также сохраняются.
Включены также доступные изображения основы E-design. Удалённый `bd.png`
восстановлен из истории официального репозитория Shikimori; старые адреса
`moe`/`dere` загружены по тем же путям через `shikimori.io`.
Единственный недоступный оригинал `Dno-fon.jpg` перечислен в `unavailable`;
его CSS-ссылка сохраняется. Шрифты в этот перенос не входят.
Авторство изображений и исходной основы переносом не изменяется.
